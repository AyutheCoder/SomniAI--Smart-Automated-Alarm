# Paper figures

Six figures, all generated by `ai-brain/evaluation/figures.py` from the same
functions that produce the numbers in `docs/`. A figure and the table it sits
beside therefore cannot drift apart.

Regenerate everything:

```
python evaluation/run_study.py --figures figures/
```

Each figure is written twice — PNG for drafts, PDF for submission.

## The figures

| # | Figure | Carries |
| --- | --- | --- |
| 1 | Inverse search, two panels | The mechanism *and* the refusal, side by side |
| 2 | Synthetic vs real | The headline finding: ~4× overstatement in R² |
| 3 | Calibration | Reliability diagram, ECE with its interval |
| 4 | Refusal quality | Over-promise rate by planner and target |
| 5 | Ablation | What each component contributes, split by failure mode |
| 6 | Across splits | Why a single split is not a result |

**Figure 1 gets two panels on purpose.** Under the infeasibility-first framing
the refusal is the contribution, so it gets equal space rather than a footnote.
The left panel shows a reachable target and the *latest* bedtime that meets it —
latest, because the objective is the least behavioural cost satisfying the
constraint. The right shows a target above the achievable ceiling, where a
forward model would still emit a number and this planner declines.

**Figure 5 splits false refusals from broken promises** rather than plotting one
accuracy number. The two failures are not equivalent: refusing something
achievable is conservative, promising something unreachable is unsound. Only one
ablation — removing the controllable/habit partition — produces the second kind,
and separating the axes is what makes that visible at a glance.

## Greyscale

IEEE proceedings are read on paper and on monochrome printers, so nothing is
distinguished by hue. Every series carries three redundant cues:

- a distinct grey level, from a palette spaced for even luminance
- a distinct line style or hatch pattern
- a distinct marker

`check_greyscale_separation` converts a palette to luminance and asserts the
smallest pairwise gap clears 0.12. The palette scores **0.18**, and
`test_the_check_rejects_a_palette_that_would_collapse` proves the check has
teeth by feeding it two blues that are obviously different on screen and
identical in print.

## Sizing

Set for a two-column IEEE layout rather than shrunk from a screen default:
3.4 in for a single column, 7.0 in full width, 400 dpi, 7–9 pt type. Figures
render at final size, so the type is the size it will be read at.

## Not committed

`figures/` is gitignored. They are generated artifacts, fully reproducible from
committed code and data, and binary files in review diffs are noise. The
reproducibility package in step 15 regenerates them.
